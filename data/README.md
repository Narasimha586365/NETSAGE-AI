# NetSage AI Troubleshooting Case Dataset

This dataset contains 30 Cisco network troubleshooting cases for the NetSage AI AICTE-Cisco Virtual Internship project.

The cases are initially synthetic, instructional examples. Their `show_output` values must be validated against Cisco Packet Tracer before they are described in a final report as actual observed output.

Each `expected_fault` records the known intended fault for a case. A small number of cases deliberately contain insufficient evidence to support responsible, low-confidence diagnosis behavior.

The dataset is intended for AI diagnosis prompting, deterministic rule checking, comparison of AI diagnosis with expected faults, and later human review.
