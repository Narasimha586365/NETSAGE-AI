# Evidence-review exercises

This document preserves five manual reviewer-training exercises for cases 5, 9, 11, 22, and 29. They are not API responses, not completed human reviews, and are excluded from dashboard metrics. They are included only to demonstrate how a reviewer should correct or reject an unsupported diagnosis.

For each exercise, the reviewer should compare the supplied symptom, topology note, and show-command output before deciding whether a diagnosis is Accepted, Edited, or Rejected. A correction must state the evidence and the reason; when evidence is incomplete, the appropriate outcome can be **Insufficient evidence** with an additional command recommendation.

Actual correction records are created only after a reviewer submits an Edited or Rejected decision in the application. Those records, not these exercises, are shown in Responsible AI analytics.
