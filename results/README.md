# NetSage AI results

These are project records, not live network telemetry.

- `diagnosis_results.csv`: structured responses from a successful configured API only.
- `human_review.csv`: records written after a reviewer explicitly saves a decision.
- `responsible_ai_log.csv`: actual Edited or Rejected review records only.
- `diagnosis_comparison.csv`: diagnosis source versus saved human outcome.
- `dashboard.html` and `dashboard_summary.csv`: generated local analytics.

No diagnosis response is created when the AI API is unavailable. Packet Tracer verification is pending until a human performs and records it.
